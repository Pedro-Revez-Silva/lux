# lux brand

The mark is a four-point star: gold (`#ffd166`) with a light facet
(`#fff4cc`) and a warm one (`#ff9f43`), outlined in navy (`#163f7a`). It is
the same on light and dark backgrounds.

| File | For |
| --- | --- |
| `lux.svg` | 48px and up: the README, docs, slides. Faceted, with a glow. |
| `lux-small.svg` | 16–32px: the favicon, the console's sidebar (the `Logo` component in `@lux/design-system` draws the same). |
| `lux-mono.svg` | One colour (`currentColor`), for places that take a single ink. |

Next to the name, the star sits left of "lux" in the semibold UI face.
